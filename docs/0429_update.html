자동 인덱싱 Tool 추가

신규 파일
tools/index_tool.py

노트를 저장할 때마다 자동으로 vectorDB에 등록하기 위해 새로 만든 파일입니다.
기존에는 저장 직후 vectorDB 등록이 제대로 되지 않아 중복 탐지·연결고리 탐색이 동작하지 않는 문제가 있었습니다.

index_note

노트 제목 또는 경로를 입력하면 해당 파일을 읽어 vectorDB에 단독 등록합니다.
노트 저장 직후 자동으로 호출됩니다.

index_all_notes

data/notes 폴더 아래 모든 마크다운 파일을 한 번에 vectorDB에 등록합니다.
vectorDB가 비어있거나 전체 재구축이 필요할 때 수동으로 실행합니다.

  • 노트 저장(save_note) → index_note 자동 호출로 연결
  • 파일→노트 변환(file_to_note) 후에도 index_note 자동 호출
  • 자동 정리 저장(organize_and_save_note) 후에도 index_note 자동 호출

중복 탐지 Tool 추가

신규 파일
tools/duplicate_tool.py

저장된 노트나 외부 파일이 이미 있는 문서와 겹치는지 확인하는 기능입니다. vectorDB에 저장된 모든 노트와 의미적 유사도를 비교합니다.

check_note_duplicates

노트 제목 또는 파일 경로를 입력하면 유사한 문서를 찾아 결과를 반환합니다.
결과는 data/duplicate_cache.json에 캐싱됩니다.

탐지 흐름

노트 제목 또는 파일 경로 입력 ↓ 파일 텍스트 추출 (형식에 따라 처리) ↓ OpenAI 임베딩 → vectorDB 코사인 유사도 검색 ↓ 자기 자신 제외 → 유사도 기준으로 분류 ↓ 공통 키워드 추출 (상위 5개) ↓ 결과 출력 + duplicate_cache.json 저장

Agent 행동 지침 수정

수정
agent/graph.py

Agent가 어떻게 행동할지 정의하는 시스템 프롬프트를 수정했습니다.

  • 노트 저장 흐름 수정 — add_to_knowledge 대신 index_note를 호출하도록 변경.
    기존 방식은 Agent가 응답 텍스트(요약문)를 전달해서 실제 파일 내용과 달라지는 문제가 있었음.
  • C-role 저장 후 자동 인덱싱 규칙 추가 — 자동 정리 저장 완료 후 index_note 호출 규칙 추가
  • file_to_note 흐름에 인덱싱 추가 — 파일→노트 변환 후 index_note까지 자동 실행
  • 전체 인덱싱 규칙 추가 — "노트 전체 인덱싱해줘" 등의 명령어를 인식하도록 추가
  • 중복 탐지 규칙 분리 — 파일 기반(check_note_duplicates)과 텍스트 기반(detect_duplicates) 규칙을 명확히 구분
